## 📖 About

Retro Recruit OS is an interactive portfolio website designed to stand out from traditional developer portfolios.

Instead of scrolling through a normal webpage, recruiters can explore my profile inside a nostalgic desktop operating system inspired by Windows 95 and classic retro computers.

The project combines modern web technologies with a vintage UI to create a memorable user experience.

---

## ✨ Features

- 🖥️ Retro desktop operating system interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/retro-recruit-os.git
```

### Navigate into the project

```bash
cd retro-recruit-os
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
